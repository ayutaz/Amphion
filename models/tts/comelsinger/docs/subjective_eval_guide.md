# 主観評価実施手順書（MOS-Q / MOS-N / SMOS）

> **チケット**: M4-12
> **論文参照**: Section IV-D (Subjective Evaluation)
> **評価者数**: 20名
> **評価スケール**: 5段階 MOS

---

## 1. 概要

CoMelSinger の歌唱音声合成品質を主観的に評価するための手順書。以下の3指標を20名の評価者により5段階で評価する。

| 指標 | 正式名称 | 評価対象 |
|------|----------|----------|
| MOS-Q | Mean Opinion Score - Quality | 音質（音声の明瞭さ、歪みの少なさ） |
| MOS-N | Mean Opinion Score - Naturalness | 自然性（人間の歌声にどれだけ近いか） |
| SMOS | Similarity Mean Opinion Score | メロディ類似度（参照音声との旋律の一致度） |

---

## 2. 評価スケール

### 2.1 MOS-Q（音質評価）

| スコア | ラベル | 基準 |
|--------|--------|------|
| 5 | 非常に良い (Excellent) | 歪みやノイズが全く感じられない、プロの録音品質 |
| 4 | 良い (Good) | わずかな歪みがあるが気にならない |
| 3 | 普通 (Fair) | 多少の歪みやノイズが知覚できるが許容範囲 |
| 2 | 悪い (Poor) | 明らかな歪みやノイズがあり不快 |
| 1 | 非常に悪い (Bad) | 聴取困難なほどの歪みやノイズ |

### 2.2 MOS-N（自然性評価）

| スコア | ラベル | 基準 |
|--------|--------|------|
| 5 | 非常に自然 (Excellent) | 人間の歌声と区別がつかない |
| 4 | 自然 (Good) | ほぼ自然だが、わずかに合成感がある |
| 3 | やや自然 (Fair) | 合成音声だと分かるが、十分に聴取可能 |
| 2 | 不自然 (Poor) | 明らかに不自然な発声・イントネーション |
| 1 | 非常に不自然 (Bad) | 機械的で人間の歌声からかけ離れている |

### 2.3 SMOS（メロディ類似度評価）

| スコア | ラベル | 基準 |
|--------|--------|------|
| 5 | 同一 (Identical) | 参照音声と完全に同じメロディ |
| 4 | 非常に類似 (Very Similar) | わずかなピッチの違いがあるが非常に近い |
| 3 | 類似 (Similar) | メロディの大枠は一致しているが部分的にずれがある |
| 2 | やや異なる (Somewhat Different) | メロディの一部が異なっている |
| 1 | 全く異なる (Completely Different) | 参照音声とは異なるメロディ |

## 3. 評価サンプルの準備

### 3.1 サンプル数

- **各条件**: 50発話（Seenセット25発話 + Unseenセット25発話）
- **比較条件**: CoMelSinger (full) + ablation 5条件 + ベースライン(MaskGCT) = 7条件
- **合計**: 50 x 7 = 350発話

### 3.2 サンプル要件

- サンプリングレート: 24kHz
- フォーマット: WAV (16bit PCM)
- 長さ: 5-15秒
- 無音区間: 前後0.5秒以内にトリミング

### 3.3 ファイル命名規則

```
{condition}_{split}_{utterance_id}.wav
例: full_seen_001.wav, wo_cl_unseen_025.wav
```

## 4. 評価者の要件と招集

### 4.1 評価者要件

- 人数: 20名（最低15名、目標20名）
- 聴力: 正常な聴力を有すること（自己申告）
- 言語: 中国語の歌唱音声を聴取できること（中国語母語話者が望ましいが必須ではない）
- 年齢: 18歳以上
- 経験: 音声品質評価の経験は不要（事前キャリブレーションで対応）

### 4.2 招集方法

1. 学内の研究室メンバー・学生からの募集（第一候補）
2. クラウドソーシング（Amazon MTurk, Prolific 等）での募集（第二候補）
3. 音声研究コミュニティでの募集（第三候補）

### 4.3 報酬

- 学内: ボランティアまたは少額謝礼
- クラウドソーシング: 時給換算で適切な報酬を設定

## 5. 評価手順

### 5.1 事前準備（キャリブレーション）

1. 評価者に評価基準を説明する文書を配布
2. **練習セッション**: 5サンプル（高品質2, 中品質2, 低品質1）を評価し、基準を理解してもらう
3. 練習セッションの結果をフィードバックし、スケールの使い方を統一

### 5.2 評価セッション

- **1セッション**: 最大50発話（約20-30分）
- **セッション数**: 7セッション（1条件/セッション）または混合配置
- **推奨配置**: 条件をランダムシャッフルして提示（順序効果を排除）
- **休憩**: 2セッションごとに5分以上の休憩を推奨

### 5.3 評価フォーム設計

#### Google Forms / Qualtrics テンプレート

各サンプルについて以下を評価：

**MOS-Q / MOS-N の場合:**
1. 音声ファイルを再生（最低1回は全体を聴取）
2. 5段階スケールで評価
3. 次のサンプルへ

**SMOS の場合:**
1. 参照音声（GT）を再生
2. 生成音声を再生
3. メロディの類似度を5段階で評価
4. 次のサンプルへ

### 5.4 注意事項

- ヘッドフォンまたはイヤホンの使用を必須とする
- 静かな環境での評価を求める
- 各サンプルは最低1回は最後まで聴取すること
- 評価中のサンプル間で音量を変更しないこと

## 6. データ収集と統計処理

### 6.1 収集データ形式

```csv
evaluator_id,condition,split,utterance_id,mos_q,mos_n,smos
E01,full,seen,001,4,4,5
E01,full,seen,002,3,4,4
...
```

### 6.2 外れ値の除外

以下の基準で不正な回答を除外：
- 全サンプルに同一スコアを付けた評価者
- 平均回答時間が3秒未満の評価者（十分に聴取していない）
- 練習セッションで基準音声（高品質/低品質）の評価が逆転している評価者

### 6.3 統計処理

```python
from models.tts.comelsinger.eval.eval_report import _format_value
import numpy as np
from scipy import stats

def compute_mos_ci(scores: list[float], confidence: float = 0.95) -> dict:
    """MOS スコアの平均と95%信頼区間を計算する。

    Args:
        scores: 評価スコアのリスト。
        confidence: 信頼水準（デフォルト: 0.95）。

    Returns:
        dict: {"mean", "ci_lower", "ci_upper", "n_raters"}
    """
    n = len(scores)
    mean = float(np.mean(scores))
    se = float(stats.sem(scores))
    ci = stats.t.interval(confidence, df=n - 1, loc=mean, scale=se)
    return {
        "mean": round(mean, 3),
        "ci_lower": round(float(ci[0]), 3),
        "ci_upper": round(float(ci[1]), 3),
        "n_raters": n,
    }
```

## 7. 倫理的配慮

- 評価者に研究の目的を説明し、同意を得る
- 個人情報（名前、メールアドレス等）は評価 ID で匿名化して管理
- データは研究目的のみに使用し、第三者に提供しない
- 評価者はいつでも評価を中断・辞退できることを事前に説明
